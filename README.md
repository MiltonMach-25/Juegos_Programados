# Juego de la Torre de Hanoi

Este proyecto contiene una implementación del clásico juego **Torre de Hanoi** en Python.  
Fue desarrollado como parte de las actividades del curso de **Diseño de Algoritmos**.

## 🎮 Descripción
La Torre de Hanoi es un juego de lógica y estrategia que consiste en mover un conjunto de discos desde una torre inicial hasta otra torre destino, siguiendo estas reglas:

1. Solo se puede mover un disco a la vez.
2. No se puede colocar un disco grande sobre uno más pequeño.
3. El objetivo es trasladar todos los discos desde la primera torre hasta la última.

## ⚙️ Características del programa
- Permite elegir entre **3 y 10 torres**.
- Permite seleccionar **diferentes tipos de discos** (colores, tamaños o números).
- Opción de orden **aleatorio u ordenado** de los discos al inicio.
- Modo de juego para **uno o varios jugadores**.
- Posibilidad de **guardar y continuar** una partida.
