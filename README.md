# Actividad Práctica – Torre de Hanoi (Recursividad)

Este programa hace parte de una **actividad práctica del curso de Diseño de Algoritmos**, donde se aplica el tema de **recursividad** usando el juego clásico de la **Torre de Hanoi** en Python.

---

## 🎯 Objetivo
Aplicar la recursividad para resolver un problema paso a paso y entender cómo un algoritmo puede llamarse a sí mismo para alcanzar una solución lógica.

---

## 🧠 Descripción del juego
La Torre de Hanoi consiste en mover todos los discos desde una torre inicial hasta una torre final, cumpliendo estas reglas:
- Solo se puede mover **un disco a la vez**.  
- No se puede colocar un disco **grande sobre uno pequeño**.  
- El objetivo es pasar todos los discos de **A hasta C**.

El código incluye un **modo interactivo** y un **modo recursivo** que muestra la solución paso a paso.

---

## ⚙️ Funciones principales
- Selección del tipo de discos (colores, tamaños o números).  
- Elección de orden (ordenado o aleatorio).  
- Modo recursivo visible.  
- Programación simple, sin librerías avanzadas.

---
